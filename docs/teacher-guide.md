# D[ai]TA Teacher Guide

## Getting Started

### Logging In
1. Navigate to the application homepage
2. Click "I'm a Teacher" 
3. Enter your username and password
   - For first-time login, use the temporary password provided by your administrator
   - You will be prompted to change your password upon first login

### Dashboard Overview
The dashboard provides quick access to:
- Student assessments
- Lesson plans
- Analytics
- Weekly groups
- Assessment creation

## Managing Assessments

### Creating New Assessments
1. Click "Create Assessment" in the navigation bar
2. Fill in the assessment details:
   - Title
   - Topic
   - Subtopics (select multiple if needed)
   - Number of questions (1-20)
   - Grade level
   - Difficulty (easy, medium, hard)
3. Click "Generate Assessment" to create questions
4. Review generated questions and make any adjustments
5. Click "Activate for Students" to make it available

### Viewing Previous Assessments
1. Navigate to "Assessments" tab
2. View list of all created assessments
3. Click on any assessment to see:
   - Questions and correct answers
   - Student performance data
   - Completion dates
   - Individual student responses

## Student Assessment Process

### For Students
1. Students click "I'm a Student" on homepage
2. Enter:
   - Student number (1-40)
   - Select teacher name
   - Choose emoji password
3. Complete active assessment
4. Submit answers to generate exit ticket

### For Teachers
1. Monitor student progress in real-time
2. Review completed assessments
3. Access auto-generated exit tickets
4. Use data to inform lesson planning

## Lesson Planning

### Individual Lesson Plans
1. Select student from dashboard
2. Review exit ticket results
3. System automatically generates personalized lesson plan with:
   - Learning objective
   - Engagement activities
   - Representation strategies
   - Action/expression tasks
   - Wrap-up activities
4. Modify suggested activities as needed
5. Save and implement lesson plan

### Group Lesson Plans
1. Navigate to "Weekly Groups" tab
2. System automatically groups students based on:
   - Similar struggle areas
   - Assessment performance
   - Grade level
3. For each group:
   - Review suggested focus areas
   - Generate group lesson plan
   - Modify activities for group setting
   - Save and implement

## Analytics

### Classroom Overview
1. Access "Classroom Analytics" tab
2. View:
   - Class average scores
   - Common struggle areas
   - Student improvement trends
   - Standards alignment

### Individual Student Analytics
1. Select specific student
2. Review:
   - Assessment history
   - Progress trends
   - Struggle areas
   - Generated lesson plans

### Weekly Groups Analytics
1. View group composition
2. Monitor:
   - Group progress
   - Common challenges
   - Collaborative improvements
   - Suggested teaching strategies

## Best Practices

### Assessment Creation
- Vary question types
- Include multiple difficulty levels
- Align with grade-level standards
- Regular assessment updates

### Student Support
- Monitor emoji password usage
- Help with technical issues
- Guide through first assessment
- Review results together

### Lesson Implementation
- Follow UDL guidelines
- Adapt suggested activities
- Document effectiveness
- Update strategies based on results

## Troubleshooting

### Common Issues
1. Login Problems
   - Verify username
   - Check caps lock
   - Contact admin for password reset

2. Assessment Access
   - Confirm activation status
   - Check student credentials
   - Verify internet connection

3. Data Sync
   - Refresh browser
   - Clear cache if needed
   - Contact support for persistent issues
